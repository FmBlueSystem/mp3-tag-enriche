# Data Module

Módulo para la gestión de persistencia de datos (SQLite) y modelos de datos de la Nueva Biblioteca.

## Submódulos

- **models/**: Submódulo para las definiciones de modelos de datos/tablas
- **repositories/**: Submódulo para los Data Access Objects (DAO) o Repositorios para interactuar con la base de datos
- **migrations/**: Submódulo para scripts de migración de base de datos

## Funcionalidades Principales

- Gestión de base de datos SQLite
- Modelos de datos para metadatos musicales
- Repositorios para acceso a datos
- Sistema de migraciones de esquema

# APIs Module

Módulo para la integración con APIs externas (Last.fm, MusicBrainz, etc.) de la Nueva Biblioteca.

## Submódulos

- **external/**: Submódulo para integraciones con servicios externos
- **clients/**: Submódulo para clientes HTTP y gestión de conexiones

## Funcionalidades Principales

- Integración con APIs de música
- Cliente HTTP optimizado
- Gestión de rate limiting
- Cache de respuestas de APIs

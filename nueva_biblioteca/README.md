# Nueva Biblioteca

Sistema inteligente de gestión de bibliotecas musicales con filtros avanzados y playlists automáticas.

## Características
- Motor de reglas para filtros musicales
- Playlists inteligentes automáticas
- Exportación a formato M3U
- Interfaz moderna con PyQt6

## Instalación
pip install -r requirements.txt

## Uso
python -m src

# UI Module

Módulo para todos los componentes de la interfaz de usuario (PyQt6) de la Nueva Biblioteca.

## Submódulos

- **components/**: Submódulo para componentes reutilizables de la UI
- **views/**: Submódulo para las vistas principales de la aplicación
- **dialogs/**: Submódulo para diálogos y ventanas modales

## Funcionalidades Principales

- Interfaz principal de la aplicación
- Componentes especializados para música
- Diálogos de configuración
- Sistema de temas y estilos

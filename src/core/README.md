# Core Module

Módulo principal para el motor de reglas, evaluador y lógica de negocio de la Nueva Biblioteca.

## Submódulos

- **parser/**: Submódulo para el parsing de expresiones de reglas
- **evaluator/**: Submódulo para la evaluación de reglas parseadas sobre los datos
- **rule_engine/**: Submódulo para el motor principal de reglas, integrando parser y evaluador
- **template_manager/**: Submódulo para la gestión de plantillas de reglas predefinidas
- **export/**: Submódulo para funcionalidades de exportación (M3U, JSON, etc.)

## Funcionalidades Principales

- Motor de reglas para filtros musicales
- Evaluación de condiciones complejas
- Gestión de plantillas de playlists inteligentes
- Exportación de resultados en múltiples formatos

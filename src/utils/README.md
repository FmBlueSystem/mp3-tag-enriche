# Utils Module

Módulo para utilidades comunes, helpers y funciones transversales de la Nueva Biblioteca.

## Submódulos

- **helpers/**: Submódulo para funciones de utilidad general
- **validators/**: Submódulo para validadores de datos
- **decorators/**: Submódulo para decoradores reutilizables

## Funcionalidades Principales

- Utilidades de archivos y paths
- Validadores de entrada
- Decoradores para logging y cache
- Helpers para formateo y conversión
